# Linear Regression: Predicting Fuel Efficiency (Auto MPG)

Research design and experiment on predicting a car's fuel efficiency (mpg) with linear models.

- `literature_review.md` - summaries of five sources
- `methodology.md` - research question, data, cleaning/feature plan, models, metrics
- `experiment.ipynb` - the experiment (on the `experiment` branch, merged into `main`)
- `data/auto_mpg.csv` - Auto MPG data (UCI Machine Learning Repository; copy from the seaborn-data repository)
